# 🏫 Defense of Minab School

A 2D defense game developed with **Python and Pygame**, inspired by the tragic attack on the school in Minab, Iran.

The game is a tribute to the innocent students and victims, turning their memory into a small interactive experience.

## 🎮 Gameplay

Your mission is to protect the school from incoming rockets.

- 🚀 **Incoming Rockets:** Rockets appear from the sky and move toward the school.
- 🎯 **Click to Destroy:** Click on incoming rockets to destroy them before they reach the school.
- 💥 **Explosions:** Rockets create explosion effects when destroyed.
- 🏫 **School Damage:** The school changes its appearance as it takes damage.
- 🚨 **Game Over:** The game ends when the school's health reaches zero.

## 🛠️ Technologies

- Python 3
- Pygame
- Sprite animations
- Pixel-perfect collision detection

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
cd school_game
```

Install dependencies:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```

## 🎯 Controls

| Key / Action | Function |
|---|---|
| Mouse Click | Destroy incoming rockets |
| Enter | Start / Resume |
| Escape | Exit the game |
